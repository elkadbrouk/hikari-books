Hikari Books Privacy Policy

Last updated: October 20, 2026

Hikari Books stores the user's library on the user's own devices. The app collects no analytics, shows no ads and sends no data to the developer or third parties.

If the user connects Google Drive, the app only accesses its own hidden app data folder (drive.appdata scope) in that user's Drive to sync the library between the user's devices. It cannot see or change other Drive files. The account email is only shown in the app settings. Tokens are stored only on the user's device; access can be revoked in the app or at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: via this project's GitHub repository.
